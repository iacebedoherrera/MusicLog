## Phase 3: User Story 1 — Verify Application Availability (Priority: P1) 🎯 MVP

**Goal**: An authenticated operational consumer receives HTTP 200 and exactly `{"status":"UP"}` from `GET /health`, with no sensitive or diagnostic data.

**Independent Test**: Run the new HTTP integration test with a token generated by the existing JWT service. The authenticated `GET` must return HTTP 200, `application/json`, and the literal one-field JSON body; an unauthenticated `GET` must not be successful; authenticated `POST /health` must return HTTP 405 and never the success body; `/v3/api-docs` must declare the matching protected closed contract.

### Tests for User Story 1

- [X] T003 [US1] Create `src/test/java/com/musiclog/shared/web/HealthControllerIntegrationTest.java` with MockMvc cases written first: valid generated JWT `GET /health` returns HTTP 200, `application/json`, and literal `{"status":"UP"}` with no extra fields; unauthenticated `GET /health` is not successful; authenticated `POST /health` returns HTTP 405 and never `{"status":"UP"}`; and `/v3/api-docs` declares `/health`, `bearerAuth`, `additionalProperties: false`, required `status`, and the sole allowed value `UP`.

### Implementation for User Story 1

- [X] T004 [P] [US1] Create `src/main/java/com/musiclog/shared/web/HealthResponse.java` as the one-field typed response whose serialized successful body is exactly `{"status":"UP"}`, with no persistence mapping, user data, configuration, diagnostic fields, or lifecycle state; define the existing-project OpenAPI schema metadata so the object is closed (`additionalProperties: false`), requires `status`, and restricts it to `UP`.
- [X] T005 [US1] Create `src/main/java/com/musiclog/shared/web/HealthController.java` with only the protected `GET /health` operation; receive the authenticated request context and obtain `AuthenticatedUser` through the established mechanism without exposing it, return `HealthResponse`, add the existing-project OpenAPI operation/security/response annotations for `bearerAuth` and the closed `UP` schema, and do not modify `SecurityConfig`.
- [X] T006 [P] [US1] Update `frontend/docs/api-contract.md` to document root-level protected `GET /health`, its JWT bearer requirement, and exact `{"status":"UP"}` response; keep this documentation-only change free of frontend client, screen, or consumer-test work.
